# BottleZero — Native apps (Android & iOS)

These native apps are **one codebase wrapped with [Capacitor](https://capacitorjs.com)**.
The React/Vite web app in `src/` is the app; Capacitor packages it into native
Android and iOS projects. You never edit two copies — you change the web app, then
re-sync.

## Update the native apps after any code change

```bash
npm run build        # rebuild the web app into dist/
npx cap sync         # copy it into android/ (and ios/ if added)
```

## Android  (works on Windows / Mac / Linux)

The real Android project is in [`android/`](android/).

1. Install **Android Studio** (free): https://developer.android.com/studio
2. Open the `android/` folder in Android Studio and let Gradle finish.
3. Press **Run** to test on an emulator/phone, or **Build → Build APK** to get an
   installable `.apk`.
4. To publish: a **Google Play Developer account** is a one-time **$25**.

App id: `com.bottlezero.app` · App name: BottleZero · Icon/splash generated from `assets/`.

## iOS  (requires a Mac — cannot be built on Windows)

Apple only allows building iOS apps on macOS with Xcode. One command sets it all up:

```bash
bash scripts/ios-setup.sh
```

It checks Xcode and Node, builds the web app, creates `ios/` (Swift Package Manager,
so no CocoaPods), syncs, adds the location-permission message the map needs, generates
the icon and splash, and opens Xcode. Then in Xcode: **App** → **Signing & Capabilities**
→ **Team** → sign in with an Apple ID → pick an iPhone simulator → **Run**.

Once it runs, commit `ios/` and push so the project is saved. After any later code
change on the Mac: `npm run build && npx cap sync ios`.

### On a real iPhone

A free Apple ID can install the app on your own iPhone over USB (it stops opening
after 7 days and needs reinstalling). Publishing needs the **Apple Developer Program**,
**$99/year**, and Apple requires the account holder to be 18+, so a parent holds it.

### Check before submitting to the App Store

- **Account deletion** is built in (Profile → Delete my account), which Apple requires
  for any app that creates accounts. It calls the `delete_my_account()` database
  function in `supabase/schema.sql`, which must exist in the live Supabase project.
- **Demo account.** App Review signs in to test the app, so make a throwaway account
  and put its email and password in the review notes in App Store Connect.
- **Export my data** and the **share card** fall back to browser downloads, which may
  not work inside the iOS app. Test both on a simulator.
- **The map's location prompt** should show "BottleZero uses your location…". If the
  app crashes when the map opens, the `Info.plist` step in the setup script didn't run.
- The **Rate BottleZero** button only appears on Android, since it links to Google Play.

## Regenerate icons / splash

Source art is generated by Python: `python scripts/generate_native_assets.py`
(creates `assets/icon.png` + `assets/splash.png`), then:

```bash
npx @capacitor/assets generate --android   # add --ios on a Mac
```

## Note

The app talks to Supabase and the impact API over the network using absolute URLs,
so it works the same inside the native shell as on the web.
