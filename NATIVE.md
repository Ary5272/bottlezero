# BottleZero — Native apps (Android & iOS)

These native apps are **one codebase wrapped with [Capacitor](https://capacitorjs.com)**.
The React/Vite web app in `src/` is the app; Capacitor packages it into native
Android and iOS projects. You never edit two copies — you change the web app, then
re-sync.

## Update the native apps after any code change

```bash
npm run build        # rebuild the web app into dist/
npx cap sync         # copy it into android/ (and ios/ if added)
```

## Android  (works on Windows / Mac / Linux)

The real Android project is in [`android/`](android/).

1. Install **Android Studio** (free): https://developer.android.com/studio
2. Open the `android/` folder in Android Studio and let Gradle finish.
3. Press **Run** to test on an emulator/phone, or **Build → Build APK** to get an
   installable `.apk`.
4. To publish: a **Google Play Developer account** is a one-time **$25**.

App id: `com.bottlezero.app` · App name: BottleZero · Icon/splash generated from `assets/`.

## iOS  (requires a Mac — cannot be built on Windows)

Apple only allows building iOS apps on macOS with Xcode. Everything is configured;
on a Mac just run:

```bash
npm install
npm run build
npx cap add ios      # creates the ios/ project (Mac only)
npx cap open ios     # opens Xcode
```

Then Run in Xcode. To publish: an **Apple Developer account** is **$99/year**.

## Regenerate icons / splash

Source art is generated by Python: `python scripts/generate_native_assets.py`
(creates `assets/icon.png` + `assets/splash.png`), then:

```bash
npx @capacitor/assets generate --android   # add --ios on a Mac
```

## Note

The app talks to Supabase and the impact API over the network using absolute URLs,
so it works the same inside the native shell as on the web.
